# Shape Up Waitlist

Pre-registration page for upcoming Shape Up with Gabby programmes.

- `index.html` is the waitlist page. Open it in a browser to preview.
- `images/` holds the logo and Gabby's photo.
- `scripts/waitlist-sheet.gs` is the Google Apps Script that saves sign-ups to the "Shape Up Waitlist Sign-ups" Google Sheet. Once deployed as a web app, its URL goes in `SHEET_URL` in `index.html`.

After signing up, people are sent to https://www.shapeupwithgabby.co.uk/resetthankyou/.
